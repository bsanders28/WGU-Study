# WGU OA Coach Free V2

Free, local-first adaptive study app.

Features:
- Adaptive practice
- Weak-area tracking
- Confidence scoring
- "I don't know" option
- Simplified spaced repetition
- Due-for-review queue
- OA Tomorrow cram planning
- OA readiness score
- Manual question bank
- Import/export community course packs
- Installable PWA
- No AI or API key required

Academic integrity:
Use only original practice questions and study materials you are allowed to use.
Do not upload/share recalled OA questions or restricted assessment content.
