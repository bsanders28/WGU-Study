WGU OA COACH — MVP

A mobile-friendly, local-first study app for practice-question coaching.

What it does:
- Create a course
- Add 4-choice practice questions with topics and explanations
- Adaptive practice prioritizes unseen and weaker topics
- Cram mode focuses on the weakest topics
- Tracks topic mastery, accuracy, and an estimated readiness score
- Export/import community-made JSON course packs
- Works as an installable PWA
- Stores progress locally in the browser

Important:
This app is intended for studying and assessment preparation. Do not use it to obtain or share protected exam questions, recalled OA content, or other restricted course materials.
